## 当前共识

1. 面向成年人，不使用低龄化密码题堆砌难度。
2. “中式恐怖”负责文化语境和情绪，“现实因果”负责真正的恐惧。
3. 玩家必须亲自完成发现、关联、排除与判断，系统不能自动公布答案。
4. 先完成剧本、时间线和证据依赖表，再大规模修改页面。
5. 三部手机可以成为三个独立章节，每部手机的年代、主人和视觉状态不同。
