# 《雾港来信》通关测试攻略

这份攻略用于功能测试，按最短闭环列出必经步骤；其余照片、聊天、地点和档案用于补全人物与小镇背景。

## 开始游戏

1. 首页点击“接入林岚的手机”。
2. 在锁屏向上滑动，或点击“向上滑动解锁”。
3. 正常滑动手机内容不会打开控制中心；只有从手机最上方状态栏向下拉才会打开。

## 第一章：回潮口

最短通关链：母女微信 → 宾馆房卡 → 306门锁缓存 → 组合推演。

1. 打开手机“微信”，进入“妈妈”，收录“6月14日母女微信”。
2. 进入“岛内地图” → “潮生宾馆” → “向前台说明身份”，取得“306备用房卡”。
3. 点击“刷卡进入306房间” → “检查电子门锁缓存”，收录“306房门卡记录”。
4. 进入“调查手记”，在“组合推演”中生成“306房间的时间断点”。
5. 进入“阶段结论”，选择以下三份材料：
   - 306房间的时间断点
   - 6月14日母女微信
   - 306房门卡记录
6. 判断选择“没有可靠记录证明她离岛，她仍在岛上的可能性最高”，提交。

数据复原测试：打开“文件” → “工作船说明.txt”，页面会提示文件异常；转到“数据复原”并开始复原，可收录工作船记录。再与客轮实名记录组合，可形成另一条合法通关论证。

## 第二章：旧名册

最短通关链：十二张启事 → 四张转院单 → 转院链推演。

1. 打开“微信” → “沈砚（旧号码）”，收录“十二张儿童寻人启事”。
2. 打开“照片” → “四张转院单”，收录转院记录。
3. 进入“调查手记”，生成“寻人启事与乙区转院链”。
4. 进入“阶段结论”，选择推演结果及其两份原始材料。
5. 判断选择“儿童经福利、医疗和港口系统被分散转运到乙区”，提交。

数据复原测试：打开“文件” → “归潮号港务内参.pdf” → “数据复原”。复原后再取得乙区值班表，可组合出“十七件救生衣不是船员物资”，这也是本章合法通关链。

## 第三章：雾笛之后

最终通关必须建立“03:17转运与付款属于同一行动”，不能用其他背景关系代替。

1. 打开“文件” → “冷链付款对账.pdf”，按提示转到“数据复原”，完成复原后收录付款记录。
2. 打开“文件” → “今晚处置日程.ics”，收录“03:17日程及检修图”。也可以在地图“白塔”检查检修门取得。
3. 进入“调查手记”，生成“03:17转运与付款属于同一行动”。
4. 进入“阶段结论”，选择：
   - 03:17转运与付款属于同一行动
   - 三份日期相邻的财务文件
   - 03:17日程及检修图
5. 判断选择“先按检修道救人并异地备份，再分层公开犯罪证据”，执行最终行动。

## 额外交互检查

- 手机“相机”：点击启用前置摄像头后，浏览器才会申请权限；可以切换镜头并拍照。第三章首次使用会出现一次短暂对焦异常。
- 第三章岛内地图：本次浏览会出现一次短暂的地下定位漂移，刷新或切换页面不会反复骚扰玩家。
- 随调查推进，微信会出现“陌生号码”。第一章内容对应306房卡，第二章对应乙区缺页，第三章会发来林岚经过冷链东门的监控背影；没有读取玩家真实位置或摄像头画面。
- 第三章同时取得“冷链付款对账”和“03:17日程”后，地图才会显示“旧港监控室”。进入后可核对宾馆、客运、便利店、冷链和白塔共用的镜像线路，并看到与威胁短信相同的背影画面。
- “高德地图”可在游戏手机内查看离线搜索结果；点击“在高德地图中继续搜索”才会新开外部高德搜索页面。
- “计算器”可以正常做一组四则运算。输入`999999`再按等号，会打开被监管设备的隐藏诊断页，但不会自动替玩家收录线索。
- 控制中心“灯”会在玩家点击后尝试申请后置摄像头补光灯权限；设备或浏览器不支持时，会明确切换为屏幕照明，拒绝权限不影响通关。
- 微信：聊天底部可选预设回复、表情、位置、照片和文件；“发现”里的扫一扫、看一看，以及“我”里的设置均有下一级页面。
- 文件、备忘录、淘宝订单、天气和音乐均可进入详情或继续操作。
- 新线索会弹出需要确认的“已收录”窗口；调查手记中的材料可再次打开查看来源、正文和未解决疑问。

## 卡关排查

- 306无法进入：先在潮生宾馆向前台说明身份取得房卡。
- 文件只显示损坏：返回桌面打开“数据复原”，不要在损坏页反复点击。
- 推演按钮未出现：两份指定原始材料必须都已收录。
- 阶段结论提交失败：必须同时选择一条能支撑本章判断的组合推演，以及该推演引用的两份原始材料。
