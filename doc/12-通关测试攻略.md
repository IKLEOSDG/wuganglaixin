# 《雾港来信》通关测试攻略

这份攻略用于功能测试，按最短闭环列出必经步骤；其余照片、聊天、地点和档案用于补全人物与小镇背景。

## 开始游戏

1. 在雾港访客网站查看“林岚”的登岛行程，点击“登岛”。
2. 在游戏手机底部的解锁手柄上向上滑动，或点击该手柄。
3. 正常滑动手机内容不会打开控制中心；只有从手机最上方状态栏向下拉才会打开。

## 第一章：回潮口

最短通关链：母女微信 → 宾馆房卡 → 306门锁缓存 → 组合推演。

1. 打开手机“微信”，进入“妈妈”，收录“6月14日母女微信”。
2. 进入“岛内地图” → “潮生宾馆” → “向前台说明身份”，取得“306备用房卡”。
3. 点击“刷卡进入306房间” → “检查电子门锁缓存”，收录“306房门卡记录”。
4. 进入“调查手记”，在“组合推演”中生成“306房间的时间断点”。
5. 进入“阶段结论”，只选择组合推演“306房间的时间断点”。原始微信和门卡记录已经保存在推演内部，不需要重复勾选。
6. 判断选择“没有可靠记录证明她离岛，她仍在岛上的可能性最高”，提交。

数据复原测试：打开“文件” → “工作船说明.txt”，页面会提示文件异常；按提示进入 App Store，在天气、扫描和潮汐工具之间找到并安装“拾遗 · 本地数据复原”。安装完成后桌面才会出现“数据复原”。恢复完成后必须点击“查看恢复内容”核对只读副本；工作船文件可与客轮实名记录形成另一条合法通关论证。

地点道具链测试：先去“望潮饭店”替旧港门岗带夜宵，再到“旧港冷链”把餐盒交给门卫。没有餐盒时，门卫不会向陌生外地人展示登记信息。

## 第二章：旧名册

最短通关链：十二张启事 → 四张转院单 → 转院链推演。

1. 第一章的微信、相册、文件、订单和备忘录仍应保留。打开新增的“沈砚（旧号码）”，收录“十二张儿童寻人启事”。
2. 打开“照片” → “四张转院单”，收录转院记录。
3. 进入“调查手记”，生成“启事与转院单出现四组对应项”。
4. 进入“阶段结论”，只选择组合推演“启事与转院单出现四组对应项”。
5. 判断选择“儿童经福利、医疗和港口系统被分散转运到乙区”，提交。

数据复原测试：打开“文件” → “归潮号港务内参.pdf” → “数据复原”。复原后再取得乙区值班表，可组合出“床位改动与救生衣领用发生在同一晚”，这也是本章合法通关链。

地点道具链测试：在“地方陈列馆”填写调阅申请，取得“档案调阅单”，再去旧港仓库调阅领用簿；向许伯出示同一张调阅单后，他才会陪玩家带备用钥匙去核对六号柜。钥匙不能带走，也不会允许玩家破坏调查机关封条。

## 第三章：雾笛之后

最终通关必须建立“03:17前后的四份记录”，不能用其他背景关系代替。

1. 打开“文件” → “冷链付款对账.pdf”。若本章设备尚未安装恢复工具，按提示从 App Store 下载；完成复原后收录付款记录。
2. 打开“文件” → “今晚处置日程.ics”，收录“03:17日程及检修图”。也可以在地图“白塔”检查检修门取得。
3. 进入“调查手记”，生成“03:17前后的四份记录”。这条推演只确认时间关系，不会代替玩家判断这些记录的真实用途。
4. 去“旧港冷链”检查无牌冷藏车，取得“冷链检修挂牌”。地图新增“地下观察区”后进入，用挂牌通过设备层，在床位终端确认LQ位置并取得“LQ床位定位截图”。
5. 付款与日程齐全后，地图显示“旧港监控室”。进入后先“复制只读镜像索引”，再断开远端观看。
6. 进入“阶段结论”，只选择“03:17前后的四份记录”。原始线索和三个行动道具不需要重复提交。
7. 判断选择“先按检修道救人并异地备份，再分层公开犯罪证据”，执行最终行动。

## 额外交互检查

- 手机“相机”：点击启用前置摄像头后，浏览器才会申请权限；可以切换镜头并拍照。第三章首次使用会出现一次短暂对焦异常。
- 第三章岛内地图：本次浏览会出现一次短暂的地下定位漂移，刷新或切换页面不会反复骚扰玩家。
- 随调查推进，微信会出现“陌生号码”。第一章内容对应306房卡，第二章对应乙区缺页，第三章会发来林岚经过冷链东门的监控背影；没有读取玩家真实位置或摄像头画面。
- 第三章同时取得“冷链付款对账”“03:17日程”和“冷链检修挂牌”后，地图才会显示“旧港监控室”。进入后可核对宾馆、客运、便利店、冷链和白塔共用的镜像线路，并看到与威胁短信相同的背影画面。
- 在第三章“旧港冷链”取得“冷链检修挂牌”后，地图才显示地下观察区；挂牌还用于进入白塔控制室。地下层确认位置后获得“LQ床位定位截图”。监控室必须先复制“监控镜像索引”，才能安全断开远端观看。这三个行动条件不会出现在结论材料勾选区。
- “高德地图”可在游戏手机内查看离线搜索结果；点击“在高德地图中继续搜索”才会新开外部高德搜索页面。
- “计算器”可以正常做一组四则运算。输入`999999`再按等号，会打开被监管设备的隐藏诊断页，但不会自动替玩家收录线索。
- 控制中心“灯”会在玩家点击后尝试申请后置摄像头补光灯权限；设备或浏览器不支持时，会明确切换为屏幕照明，拒绝权限不影响通关。
- 微信：聊天底部可选预设回复、表情、位置、照片和文件；快捷回复面板应完整显示在输入栏上方。给妈妈发消息后，先显示自己的绿色气泡，约1.5秒后再出现居中的系统提示“消息未送达”，不能出现妈妈的回复气泡。语音和🎥视频通话均会等待后显示无人接听。
- 第二、三章仍使用林岚的同一部手机。旧联系人和旧内容不能消失或自行变化；郭宁聊天以“导入备份”只读展示，不提供回复与通话入口。
- 文件、备忘录、淘宝订单、天气和音乐均可进入详情或继续操作。
- 新线索会弹出需要确认的“已收录”窗口；调查手记中的材料可再次打开查看来源、正文和未解决疑问。

## 卡关排查

- 306无法进入：先在潮生宾馆向前台说明身份取得房卡。
- 文件只显示损坏：按文件页提示进入 App Store 安装“拾遗”；安装后回桌面打开“数据复原”。
- 推演按钮未出现：两份指定原始材料必须都已收录。
- 阶段结论提交失败：只选择一条能支撑本章判断的组合推演，再检查判断选项是否与这条推演一致。
